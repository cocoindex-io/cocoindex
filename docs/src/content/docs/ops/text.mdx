## Available functions and classes

### `detect_code_language()`

Detect the programming language from a filename.

**Usage:**

{/* Rust: rust/sdk/cocoindex/src/ops/text.rs (doctest), rust/sdk/cocoindex/tests/ops_text.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.ops.text import detect_code_language

language = detect_code_language(filename="main.py")
print(language)  # "python"

language = detect_code_language(filename="app.rs")
print(language)  # "rust"

language = detect_code_language(filename="unknown.xyz")
print(language)  # None
```

</Fragment>
<Fragment slot="rust">

```rust
use cocoindex::ops::text::detect_code_language;

assert_eq!(detect_code_language("main.py").as_deref(), Some("python"));
assert_eq!(detect_code_language("app.rs").as_deref(), Some("rust"));
assert_eq!(detect_code_language("file.xyz"), None);
```

It returns `Option<String>`: `None` when the extension is not recognized.

</Fragment>
</LangTabs>

### `SeparatorSplitter`

Split text by regex separators.

**Usage:**

{/* Rust: rust/sdk/cocoindex/tests/ops_text.rs (separator_splitter_basic, separator_splitter_keep_separator_left) */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.ops.text import SeparatorSplitter

splitter = SeparatorSplitter([r"\.\s+"], keep_separator="left")

text = "First sentence. Second sentence. Third sentence."
chunks = splitter.split(text)

for chunk in chunks:
    print(chunk.text)
```

</Fragment>
<Fragment slot="rust">

```rust
use cocoindex::ops::text::{KeepSeparator, SeparatorSplitConfig, SeparatorSplitter};

// Separators only.
let splitter = SeparatorSplitter::new([r"\n\n+"])?;
let text = "Para1\n\nPara2\n\nPara3";
let chunks = splitter.split(text);
for chunk in &chunks {
    println!("{}", chunk.text(text));
}

// Keep the separator on the left of the split.
let splitter = SeparatorSplitter::with_config(SeparatorSplitConfig {
    separators_regex: vec![r"\.".to_string()],
    keep_separator: Some(KeepSeparator::Left),
    ..Default::default()
})?;
```

`SeparatorSplitter::new(separators)` takes the regex list; the other options (`keep_separator`, `trim`) go through `SeparatorSplitConfig` and `with_config`. A `Chunk` does not hold its text: call `chunk.text(text)` with the string you split.

</Fragment>
</LangTabs>

Use `RecursiveSplitter` below to configure chunk size and overlap.

### `RecursiveSplitter`

Advanced text chunking with language awareness and syntax-aware splitting for code. Returns [`Chunk`](../common_resources/data_types#chunk) objects with position information.

**Features:**
- Supports many programming languages
- Preserves code structure: a function, class or block that fits in `chunk_size` stays in one chunk, and a header, such as a `def` or `if` line or a Markdown heading, stays with the start of its body
- Customizable chunk sizes and overlap
- Returns [`Chunk`](../common_resources/data_types#chunk) objects with start/end positions (line, column, byte/char offsets)

**Usage:**

{/* Rust: examples/rust/text_embedding/src/main.rs, rust/sdk/cocoindex/tests/ops_text.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.ops.text import RecursiveSplitter

splitter = RecursiveSplitter()

# Split markdown text
text = "# Title\n\nParagraph 1.\n\nParagraph 2."
chunks = splitter.split(
    text,
    chunk_size=2000,
    chunk_overlap=500,
    language="markdown"
)

for chunk in chunks:
    print(f"Chunk: {chunk.text}")
    print(f"Start: line {chunk.start.line}, char {chunk.start.char_offset}")
    print(f"End: line {chunk.end.line}, char {chunk.end.char_offset}")
```

</Fragment>
<Fragment slot="rust">

```rust
use cocoindex::ops::text::{RecursiveChunkConfig, RecursiveSplitter};

let splitter = RecursiveSplitter::new()?;

// Split markdown text
let text = "# Title\n\nParagraph 1.\n\nParagraph 2.";
let chunks = splitter.split_with(
    text,
    RecursiveChunkConfig {
        chunk_size: 2000,
        min_chunk_size: None,
        chunk_overlap: Some(500),
        language: Some("markdown".to_string()),
    },
);

for chunk in &chunks {
    println!("Chunk: {}", chunk.text(text));
    println!("Start: line {}, char {}", chunk.start.line, chunk.start.char_offset);
    println!("End: line {}, char {}", chunk.end.line, chunk.end.char_offset);
}

// With only a chunk size: default minimum, no overlap, no language hint.
let chunks = splitter.split("Short text.", 100);
```

`RecursiveSplitter::new()` returns a `Result`. `split(text, chunk_size)` uses the defaults; `split_with(text, config)` takes a `RecursiveChunkConfig` with `chunk_size`, `min_chunk_size` (a soft floor, default `chunk_size / 2`), `chunk_overlap` and `language`. Sizes are in bytes.

</Fragment>
</LangTabs>

**Reusing one parse across APIs:**

When the same code is passed to several parse-consuming APIs (e.g. splitting *and*
structural pattern matching), wrap it in a `CodeSource` so it is parsed at most once.
The `CodeSource` carries its own language, so <Lang only="python">the `language=` argument must be omitted</Lang><Lang only="rust">`config.language` is ignored</Lang>:

{/* Rust: CodeSource::with_language and RecursiveSplitter::split_source from rust/sdk/cocoindex/src/ops/text.rs (signatures); CodePattern::compile from rust/sdk/cocoindex/tests/code.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.ops.code import CodePattern, CodeSource

src = CodeSource(python_code, language="python")
chunks = splitter.split(src, chunk_size=1000)          # parses once
defs = CodePattern(r"def \NAME(\(A*\)):", language="python").match_source(src)  # reuses the parse
```

</Fragment>
<Fragment slot="rust">

```rust
use cocoindex::ops::text::{CodeSource, RecursiveChunkConfig, RecursiveSplitter};

let src = CodeSource::with_language(python_code, "python");
let chunks = splitter.split_source(
    &src,
    RecursiveChunkConfig {
        chunk_size: 1000,
        min_chunk_size: None,
        chunk_overlap: None,
        language: None, // the source carries its own language
    },
);
```

`RecursiveSplitter::split_source(&source, config)` reuses the parse cached in a `CodeSource`; the source's language wins, so `config.language` is ignored. The structural matcher lives in `cocoindex::ops::code` (feature `code_match`): `CodeAst::new(code, "python")?` parses once and offers `matches(pattern)`, `matches_with(&CodePattern::compile(pattern, "python")?)` and `split(chunk_size, min_chunk_size, chunk_overlap)` over that one parse. `render_match(&ast, &matches[0])` renders a match as a `SourceView`: the head lines of its enclosing scopes as `SegmentKind::Frame` segments, an elision cue, then the matched code verbatim, with `view.text` ready to embed or display and `view.segments` mapping each piece back to its source range.

</Fragment>
</LangTabs>

**Supported languages:**

<Lang only="python">`language=`</Lang><Lang only="rust">`language`</Lang> accepts a language name, an alternate name, or a file extension — `"python"`, `"py"` and `".py"` all select Python. Matching is case-insensitive. Use [`detect_code_language()`](#detect_code_language) to infer the value from a filename.

### `CustomLanguageConfig`

Define custom language splitting rules.

**Usage:**

{/* Rust: rust/sdk/cocoindex/tests/ops_text.rs (custom_language_config_and_alias) */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.ops.text import CustomLanguageConfig, RecursiveSplitter

# Create custom language config for abstracts
abstract_config = CustomLanguageConfig(
    language_name="abstract",
    separators_regex=[
        r"[.?!]+\s+",  # Sentence boundaries
        r"[:;]\s+",     # Clause boundaries
        r",\s+",        # Comma boundaries
        r"\s+",         # Whitespace
    ]
)

splitter = RecursiveSplitter(custom_languages=[abstract_config])

chunks = splitter.split(
    "This is a sample abstract. It has multiple sentences...",
    chunk_size=500,
    chunk_overlap=150,
    language="abstract"
)
```

</Fragment>
<Fragment slot="rust">

```rust
use cocoindex::ops::text::{CustomLanguageConfig, RecursiveChunkConfig, RecursiveSplitter};

let config = CustomLanguageConfig {
    language_name: "myformat".to_string(),
    aliases: vec!["mf".to_string()],
    separators_regex: vec![r"---".to_string()],
};
let splitter = RecursiveSplitter::with_custom_languages(vec![config])?;

let text = "Part1---Part2---Part3";
let chunks = splitter.split_with(
    text,
    RecursiveChunkConfig {
        chunk_size: 10,
        min_chunk_size: Some(3),
        chunk_overlap: None,
        language: Some("myformat".to_string()),
    },
);
```

`CustomLanguageConfig` has the three fields `language_name`, `aliases` and `separators_regex`; `RecursiveSplitter::with_custom_languages(configs)?` registers them.

</Fragment>
</LangTabs>
