## As target

The `doris` connector provides target state APIs for writing rows to tables. CocoIndex tracks what rows should exist and automatically handles upserts and deletions via Doris stream load.

### Declaring target states

#### Setting up a connection

<Lang only="python">

Create a `ContextKey[doris.ManagedConnection]` to identify your connection, then provide it in your lifespan:

</Lang>

<Lang only="rust">

Declare a context key for a `DorisConnection` with `cocoindex::context_key!`, then provide the connection when you build the environment:

</Lang>

:::note
The key name is load-bearing across runs — it's the stable identity CocoIndex uses to track managed rows. See [ContextKey as stable identity](../programming_guide/context#contextkey-as-stable-identity) before renaming.

CocoIndex tracks each table by the context key and the table name. The `database` in <Lang only="python">`DorisConnectionConfig`</Lang><Lang only="rust">`DorisConfig`</Lang> is not part of that identity. If you change `database` under the same key, CocoIndex treats it as if you moved the tables there. It assumes that they already exist in the new database, so it does not create them, and it leaves the old database as it is. To write to a new, empty database, use a new context key.
:::

{/* Rust: rust/sdk/cocoindex/tests/doris_target.rs */}
<LangTabs>
<Fragment slot="python">

```python
import cocoindex as coco
from cocoindex.connectors import doris

DORIS_DB = coco.ContextKey[doris.ManagedConnection]("my_doris")

@coco.lifespan
def coco_lifespan(builder: coco.EnvironmentBuilder) -> Iterator[None]:
    conn = doris.connect(doris.DorisConnectionConfig(
        fe_host="localhost",
        database="my_database",
    ))
    builder.provide(DORIS_DB, conn)
    yield
    # conn is cleaned up after yield
```

</Fragment>

<Fragment slot="rust">

```rust
impl TableSchema {
    pub fn from_row<T: SchemaFields>(
        primary_key: impl IntoIterator<Item = impl Into<String>>,
    ) -> Result<Self>

    pub fn with_vector_dim(self, field_name: &str, dim: usize) -> Result<Self>
    pub async fn with_vector_schema(
        self,
        field_name: &str,
        provider: &(impl VectorSchemaProvider + ?Sized),
    ) -> Result<Self>
    pub fn with_column_type(self, field_name: &str, doris_type: impl Into<String>) -> Result<Self>
}
```

The row type is a struct that derives `SchemaFields` (and `Serialize`). Per-column overrides are builder calls on the derived schema: `with_vector_schema` (from an embedder or other `VectorSchemaProvider`) or `with_vector_dim` for a vector column, `with_column_type` for a type override, which keeps the column's nullability and makes it a non-vector column.

</Fragment>
</LangTabs>

<Lang only="python">

**Parameters:**

- `record_type` — A record type whose fields define table columns.
- `primary_key` — List of column names forming the primary key.
- `column_overrides` — Optional per-column overrides for type mapping or vector configuration.

</Lang>

<Fragment slot="rust">

```rust
#[derive(Clone, Serialize, Deserialize, SchemaFields)]
struct DocEmbedding {
    id: i64,
    text: String,
    #[coco(vector)]
    embedding: Vec<f32>,
}

let schema = doris::TableSchema::from_row::<DocEmbedding>(["id"])?
    .with_vector_schema("embedding", ctx.get_key(&EMBEDDER)?)
    .await?;
```

`#[coco(vector)]` marks an `ARRAY<FLOAT>` vector column whose dimension is set with `with_vector_dim` or `with_vector_schema`; `#[coco(vector = 384)]` fixes it in the struct. `Option<T>` fields become nullable columns.

</Fragment>
</LangTabs>

<Lang only="python">

Python types are automatically mapped to Doris types:

| Python Type | Doris Type |
|-------------|------------|
| `bool` | `BOOLEAN` |
| `int` | `BIGINT` |
| `float` | `DOUBLE` |
| `decimal.Decimal` | `TEXT` |
| `str` | `TEXT` |
| `bytes` | `STRING` |
| `uuid.UUID` | `VARCHAR(36)` |
| `datetime.datetime` | `DATETIME(6)` |
| `datetime.date` | `DATE` |
| `datetime.time` | `VARCHAR(20)` |
| `datetime.timedelta` | `BIGINT` (microseconds) |
| `list`, `dict`, nested structs | `JSON` |
| `NDArray` (with vector schema) | `ARRAY<FLOAT>` |

`bytes` values are decoded as UTF-8 before writing to `STRING`; invalid UTF-8 sequences are replaced.

#### DorisType

Use `DorisType` to specify a custom Doris type:

</Lang>

<Lang only="rust">

Rust field types are automatically mapped to Doris types:

| Rust Type | Doris Type |
|-----------|------------|
| `bool` | `BOOLEAN` |
| `i16`, `i32`, `i64` | `BIGINT` |
| `f32`, `f64` | `DOUBLE` |
| `Decimal` | `TEXT` |
| `String` | `TEXT` |
| `Vec<u8>` | `STRING` (base64) |
| `Uuid` | `VARCHAR(36)` |
| `DateTime`, `NaiveDateTime` | `DATETIME(6)` |
| `NaiveDate` | `DATE` |

`Vec<u8>` values are base64-encoded before writing to `STRING` so arbitrary binary data survives Doris's JSON Stream Load path.

### Vector indexes

Doris supports vector similarity search via HNSW and IVF indexes. Define them with `VectorIndexDef`:

{/* Rust: rust/sdk/cocoindex/src/connectors/doris.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.connectors.doris import VectorIndexDef

vector_idx = VectorIndexDef(
    field_name="embedding",
    index_type="HNSW",       # or "IVF"
    metric_type="l2_distance",  # or "cosine_distance"
)
```

</Fragment>
<Fragment slot="rust">

```rust
pub struct VectorIndexDef {
    pub field_name: String,
    pub index_type: String,   // "HNSW" (default) or "IVF"
    pub metric_type: String,  // "l2_distance" (default), "inner_product", "cosine_distance"
    pub max_degree: Option<u32>,
    pub ef_construction: Option<u32>,
    pub nlist: Option<u32>,
}

impl VectorIndexDef {
    pub fn new(field_name: impl Into<String>) -> Self
    pub fn index_type(self, index_type: impl Into<String>) -> Self
    pub fn metric_type(self, metric: impl Into<String>) -> Self
    pub fn max_degree(self, v: u32) -> Self
    pub fn ef_construction(self, v: u32) -> Self
    pub fn nlist(self, v: u32) -> Self
}
```

`VectorIndexDef::new("embedding")` is an HNSW index with `l2_distance`; the builder methods change the rest. Pass the list in `DorisTableOptions::vector_indexes`.

</Fragment>
</LangTabs>

**Parameters:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `field_name` | *(required)* | Column to index |
| `index_type` | `"HNSW"` | Index type: `"HNSW"` or `"IVF"` |
| `metric_type` | `"l2_distance"` | Distance metric: `"l2_distance"`, `"inner_product"` or `"cosine_distance"` |
| `max_degree` | `None` | HNSW max degree |
| `ef_construction` | `None` | HNSW construction parameter |
| `nlist` | `None` | IVF number of partitions |

<LangTabs>
<Fragment slot="python">

```python
from typing import Annotated, Iterator
from dataclasses import dataclass

from numpy.typing import NDArray

import cocoindex as coco
from cocoindex.connectors import doris
from cocoindex.ops.sentence_transformers import SentenceTransformerEmbedder

DORIS_DB = coco.ContextKey[doris.ManagedConnection]("my_doris")

embedder = SentenceTransformerEmbedder("sentence-transformers/all-MiniLM-L6-v2")

@dataclass
class DocEmbedding:
    id: int
    text: str
    embedding: Annotated[NDArray, embedder]

@coco.lifespan
def coco_lifespan(builder: coco.EnvironmentBuilder) -> Iterator[None]:
    conn = doris.connect(doris.DorisConnectionConfig(
        fe_host="localhost",
        database="my_database",
    ))
    builder.provide(DORIS_DB, conn)
    yield

@coco.fn
async def app_main() -> None:
    table = await doris.mount_table_target(
        DORIS_DB,
        "doc_embeddings",
        await doris.TableSchema.from_class(
            DocEmbedding,
            primary_key=["id"],
        ),
        vector_indexes=[
```
