The `turbopuffer` connector provides utilities for writing rows to [Turbopuffer](https://turbopuffer.com/) namespaces, with support for both single and named vectors.

## Connection setup

Turbopuffer uses a single client object that owns the API key and region. Construct one using `AsyncTurbopuffer`:

{/* Rust: examples/rust/text_embedding_turbopuffer/src/main.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.connectors import turbopuffer

client = turbopuffer.AsyncTurbopuffer(
    region="gcp-us-central1",
    api_key=os.environ["TURBOPUFFER_API_KEY"],
)
```

</Fragment>
<Fragment slot="rust">

```rust
fn connect() -> Result<TurbopufferConnection> {
    let api_key = std::env::var("TURBOPUFFER_API_KEY")
        .map_err(|_| Error::engine("TURBOPUFFER_API_KEY is required"))?;
    let region = std::env::var("TURBOPUFFER_REGION").unwrap_or_else(|_| "gcp-us-central1".into());
    Ok(TurbopufferConnection::new(&region, &api_key))
}
```

`TurbopufferConnection::new(region, api_key)` is synchronous: it builds an HTTP client for `https://{region}.turbopuffer.com`. `with_base_url(url)` points it elsewhere, for a mock server in tests.

</Fragment>
</LangTabs>

`turbopuffer.AsyncTurbopuffer` is re-exported from the [Turbopuffer Python SDK](https://github.com/turbopuffer/turbopuffer-python); importing it directly via `from turbopuffer import AsyncTurbopuffer` works too. The Rust SDK speaks the Turbopuffer HTTP API itself and uses no Turbopuffer crate.

## As target

The `turbopuffer` connector provides target state APIs for writing rows to namespaces. CocoIndex tracks what rows should exist and automatically handles upserts and deletions. Turbopuffer creates namespaces implicitly on the first write, so there is no separate "create namespace" step — but the connector still tracks namespace-level configuration (vector schema and distance metric) and clears the namespace if it must be rebuilt.

### Declaring target states

#### Setting up a connection

Create a `ContextKey[AsyncTurbopuffer]` to identify your client, then provide it in your lifespan:

:::note
The key name is load-bearing across runs — it's the stable identity CocoIndex uses to track managed namespaces. See [ContextKey as stable identity](../programming_guide/context#contextkey-as-stable-identity) before renaming.
:::

{/* Rust: examples/rust/text_embedding_turbopuffer/src/main.rs, rust/sdk/cocoindex/tests/turbopuffer_target.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.connectors import turbopuffer
import cocoindex as coco

TPUF = coco.ContextKey[turbopuffer.AsyncTurbopuffer]("my_vectors")

@coco.lifespan
async def coco_lifespan(builder: coco.EnvironmentBuilder) -> AsyncIterator[None]:
    client = turbopuffer.AsyncTurbopuffer(
        region="gcp-us-central1",
        api_key=os.environ["TURBOPUFFER_API_KEY"],
    )
    builder.provide(TPUF, client)
    yield
```

</Fragment>


#### Namespaces (parent state)

Declares a namespace as a target state. Returns a `NamespaceTarget` for declaring rows.

{/* Rust: rust/sdk/cocoindex/src/connectors/turbopuffer.rs */}
<LangTabs>
<Fragment slot="python">

```python
def declare_namespace_target(
    db: ContextKey[AsyncTurbopuffer],
    namespace_name: str,
    schema: NamespaceSchema,
    *,
    managed_by: Literal["system", "user"] = "system",
) -> NamespaceTarget[coco.PendingS]
```

</Fragment>
<Fragment slot="rust">

```rust
pub fn declare_namespace_target(
    ctx: &Ctx,
    conn: &ContextKey<TurbopufferConnection>,
    namespace: impl Into<String>,
    schema: NamespaceSchema,
) -> Result<NamespaceTarget>

pub async fn mount_namespace_target(
    ctx: &Ctx,
    conn: &ContextKey<TurbopufferConnection>,
    namespace: impl Into<String>,
    schema: NamespaceSchema,
) -> Result<NamespaceTarget>
```

`managed_by` is set with `ManagedTargetOptions::user_managed()` on the `_with_options` variants (`declare_namespace_target_with_options`, `mount_namespace_target_with_options`). `declare_namespace_target` returns a handle whose rows resolve when the current component commits; `mount_namespace_target(...).await?` returns a handle that accepts rows at once.

</Fragment>
</LangTabs>

**Parameters:**

- `db` — A `ContextKey[AsyncTurbopuffer]` identifying the client to use.
- `namespace_name` — Name of the namespace.
- `schema` — Schema definition specifying vector configuration and distance metric (see [Namespace schema](#namespace-schema)).
- `managed_by` — Whether CocoIndex manages the namespace lifecycle (`"system"`) or assumes it exists (`"user"`).

**Returns:** A pending `NamespaceTarget`. Use the convenience wrapper `await turbopuffer.mount_namespace_target(TPUF, namespace_name, schema)` to resolve.

#### Rows (child states)

Once a `NamespaceTarget` is resolved, declare rows to be upserted using `turbopuffer.Row`:

{/* Rust: rust/sdk/cocoindex/src/connectors/turbopuffer.rs */}
<LangTabs>
<Fragment slot="python">

```python
def NamespaceTarget.declare_row(
    self,
    row: turbopuffer.Row,
) -> None
```

`Row` is a small dataclass:

```python
@dataclass
class Row:
    id: str | int
    vector: Sequence[float] | np.ndarray | dict[str, Sequence[float] | np.ndarray]
    attributes: dict[str, Any] | None = None
```

</Fragment>
<Fragment slot="rust">

```rust
impl NamespaceTarget {
    /// A row for an unnamed-vector namespace.
    pub fn declare_row(
        &self,
        ctx: &Ctx,
        id: impl Into<String>,
        vector: Vec<f32>,
        attributes: Map<String, JsonValue>,
    ) -> Result<()>

    /// A row for a named-vector namespace.
    pub fn declare_named_row<I, K>(
        &self,
        ctx: &Ctx,
        id: impl Into<String>,
        vectors: I,
        attributes: Map<String, JsonValue>,
    ) -> Result<()>
    where
        I: IntoIterator<Item = (K, Vec<f32>)>,
        K: Into<String>
}
```

The Rust SDK has no `Row` type: the id, the vector(s) and the attributes are separate arguments. The id is a `String`; the attributes are a `serde_json::Map<String, Value>`. A vector with a NaN or infinite element is rejected.

</Fragment>
</LangTabs>

- `id` — Document id (string or integer).
- `vector` — For an unnamed-vector schema, pass a single sequence. For a named-vectors schema, pass a dict mapping vector field name to its sequence.
- `attributes` — Non-vector attributes (text, tags, metadata, etc.). Turbopuffer infers attribute types from the data.

### Namespace schema

Define vector configuration and distance metric for a namespace using `NamespaceSchema`:

{/* Rust: rust/sdk/cocoindex/src/connectors/turbopuffer.rs */}
<LangTabs>
<Fragment slot="python">

```python
class NamespaceSchema:
    @classmethod
    async def create(
        cls,
        vectors: VectorDef | dict[str, VectorDef],
        *,
        distance: Literal["cosine_distance", "euclidean_squared"] = "cosine_distance",
    ) -> NamespaceSchema
```

</Fragment>
<Fragment slot="rust">

```rust
impl NamespaceSchema {
    // One unnamed f32 vector under Turbopuffer's `vector` field
    pub fn new(vector_size: usize, distance: DistanceMetric) -> Self
    pub fn from_vector_schema(schema: VectorSchema, distance: DistanceMetric) -> Result<Self>
    pub async fn from_vector_provider(
        provider: &(impl VectorSchemaProvider + ?Sized),
        distance: DistanceMetric,
    ) -> Result<Self>

    // Named vectors
    pub fn named<I, K>(vectors: I, distance: DistanceMetric) -> Result<Self>
    where
        I: IntoIterator<Item = (K, VectorDef)>,
        K: Into<String>

    // Named vectors from a `#[derive(SchemaFields)]` row
    pub fn from_row<T: SchemaFields>(distance: DistanceMetric) -> Result<Self>
    pub fn with_vector_dim(self, field_name: &str, dim: usize) -> Result<Self>
}

pub enum DistanceMetric { CosineDistance, EuclideanSquared }
```

The Rust schema has one constructor per shape instead of one `create` with a union argument. `from_row` turns each `#[coco(vector)]` field of a row struct into a named vector; the other fields stay schemaless attributes. Every constructor takes the distance explicitly.

</Fragment>
</LangTabs>

**Parameters:**

- `vectors` — Either:
  - A single `VectorDef` for an unnamed vector (stored under turbopuffer's default `"vector"` field).
  - A dict mapping vector names to `VectorDef` for named vectors.
- `distance` — Distance metric applied to all vector columns in the namespace. Turbopuffer applies a single distance metric per namespace.

#### VectorDef

Specifies a vector field's dimension and dtype:

{/* Rust: rust/sdk/cocoindex/src/connectors/turbopuffer.rs */}
<LangTabs>
<Fragment slot="python">

```python
class VectorDef(NamedTuple):
    schema: VectorSchemaProvider | ContextKey[VectorSchemaProvider]
```

</Fragment>
<Fragment slot="rust">

```rust
pub struct VectorDef {
    pub schema: VectorSchema,
}

impl VectorDef {
    pub fn new(schema: VectorSchema) -> Result<Self>
    pub fn f32(size: usize) -> Result<Self>
    pub async fn from_provider(provider: &(impl VectorSchemaProvider + ?Sized)) -> Result<Self>
}
```

</Fragment>
</LangTabs>

The `schema` field accepts a [`VectorSchemaProvider`](../common_resources/vector_schema#vectorschemaprovider), a `ContextKey`, or an explicit `VectorSchema`. The dtype on the `VectorSchema` (must be `np.dtype(np.float32)` or `np.dtype(np.float16)`) controls turbopuffer's vector type — `[N]f32` or `[N]f16`. In Rust, `VectorSchema::f32(n)` and `VectorSchema::f16(n)` select the same two types, and `VectorDef::from_provider(&embedder).await?` resolves one from an embedder.

#### Single (unnamed) vector

For namespaces with a single unnamed vector:

#### Named vectors

Namespaces can have multiple named vector columns (turbopuffer supports up to two per namespace). The name `"id"` is reserved for the row id and cannot be used as a vector field name.

{/* Rust: rust/sdk/cocoindex/src/connectors/turbopuffer.rs (unit tests), examples/rust/text_embedding_turbopuffer/src/main.rs */}
<LangTabs>
<Fragment slot="python">

```python
from cocoindex.resources.schema import VectorSchema
import numpy as np

schema = await turbopuffer.NamespaceSchema.create(
    vectors={
        "text_embedding": turbopuffer.VectorDef(
            schema=VectorSchema(dtype=np.dtype(np.float32), size=384),
        ),
        "image_embedding": turbopuffer.VectorDef(
            schema=VectorSchema(dtype=np.dtype(np.float32), size=512),
        ),
    },
    distance="cosine_distance",
)
```

Rows pass a dict of vectors:

```python
target.declare_row(turbopuffer.Row(
    id="doc-123",
    vector={
        "text_embedding": text_vec,
        "image_embedding": image_vec,
    },
    attributes={"title": "..."},
))
```

</Fragment>
<Fragment slot="rust">

```rust
let schema = NamespaceSchema::named(
    [
        ("text", VectorDef::f32(3)?),
        ("image", VectorDef::f32(2)?),
    ],
    DistanceMetric::CosineDistance,
)?;
```

Rows pass `(name, vector)` pairs to `declare_named_row`:

```rust

    &ctx,
    r.id.clone(),

    attributes,

```

### Distance metrics

Turbopuffer applies a single `distance_metric` per namespace. Supported values:

- `"cosine_distance"` — Cosine distance (default).
- `"euclidean_squared"` — Squared Euclidean distance.

In Rust these are `DistanceMetric::CosineDistance` and `DistanceMetric::EuclideanSquared`; every constructor takes the metric explicitly.

### Example

{/* Rust: examples/rust/text_embedding_turbopuffer/src/main.rs */}

```python
from typing import AsyncIterator
import os
import cocoindex as coco
from cocoindex.connectors import turbopuffer
from cocoindex.ops.sentence_transformers import SentenceTransformerEmbedder

TPUF = coco.ContextKey[turbopuffer.AsyncTurbopuffer]("main_vectors")

embedder = SentenceTransformerEmbedder("sentence-transformers/all-MiniLM-L6-v2")

@coco.lifespan
async def coco_lifespan(builder: coco.EnvironmentBuilder) -> AsyncIterator[None]:
    client = turbopuffer.AsyncTurbopuffer(
        region="gcp-us-central1",
        api_key=os.environ["TURBOPUFFER_API_KEY"],
    )
    builder.provide(TPUF, client)
    yield

@coco.fn
async def process_document(
    doc_id: str,
    text: str,
    target: turbopuffer.NamespaceTarget,
) -> None:
    embedding = await embedder.embed(text)
    target.declare_row(turbopuffer.Row(
        id=doc_id,
        vector=embedding,
        attributes={"text": text},
    ))

@coco.fn
async def app_main() -> None:
    namespace = await turbopuffer.mount_namespace_target(
        TPUF,
        "documents",
        await turbopuffer.NamespaceSchema.create(
            vectors=turbopuffer.VectorDef(schema=embedder),
        ),
    )

    for doc_id, text in documents:
        await coco.mount(
            coco.component_subpath("doc", doc_id),
            process_document,
            doc_id,
            text,
            namespace,
        )
```

```rust
use std::path::PathBuf;

use cocoindex::connectors::turbopuffer::{
    self, DistanceMetric, NamespaceSchema, TurbopufferConnection,
};
use cocoindex::ops::sentence_transformers::SentenceTransformerEmbedder;
use cocoindex::prelude::*;
use serde_json::json;

cocoindex::context_key!(static DB: TurbopufferConnection);
cocoindex::context_key!(
    static EMBEDDER: SentenceTransformerEmbedder,
    detect_change
);

#[derive(Clone, Serialize, Deserialize, SchemaFields)]
struct RowData {
    id: String,
    #[coco(vector)]
    vector: Vec<f32>,
    filename: String,
    chunk_start: i64,
    chunk_end: i64,
    text: String,
}

#[cocoindex::function]
async fn process_file(ctx: &Ctx, file: FileEntry) -> Result<Vec<RowData>> {
    // chunk and embed the file ...
}

async fn app_main(ctx: Ctx, sourcedir: PathBuf, namespace: String) -> Result<()> {
    let vector_dim = ctx.get_key(&EMBEDDER)?.dimension();
    let target = turbopuffer::mount_namespace_target(
        &ctx,
        &DB,
        &namespace,
        NamespaceSchema::from_row::<RowData>(DistanceMetric::CosineDistance)?
            .with_vector_dim("vector", vector_dim)?,
    )
    .await?;

    let files = walk_items(&sourcedir, &["**/*.md"])?;
    let rows_by_file = mount_each!(files, |file| process_file(ctx, file)).await?;

    for rows in &rows_by_file {
        for r in rows {
            let attributes = json!({
                "filename": r.filename,
                "chunk_start": r.chunk_start,
                "chunk_end": r.chunk_end,
                "text": r.text,
            })
            .as_object()
            .unwrap()
            .clone();
            target.declare_named_row(
                &ctx,
                r.id.clone(),
                [("vector", r.vector.clone())],
                attributes,
            )?;
        }
    }
    Ok(())
}
```

## Row IDs

Turbopuffer rows are identified by `str` or `int`. UUIDs should be passed as strings. In Rust, the id is always a `String` (`impl Into<String>`).

## Attributes

Row attributes are schemaless; turbopuffer infers attribute types from the values you write. Supported scalar types include `string`, `int`, `uint`, `float`, `bool`, `uuid`, and `datetime`, plus their array variants. See [Turbopuffer's schema reference](https://turbopuffer.com/docs/write#schema) for the full list. In Rust, the attributes are a `serde_json::Map<String, Value>`.

Reserved attribute names depend on the schema; putting any reserved name in `Row.attributes` raises a `ValueError`:

- `id` is always reserved — it's the row id.
- For an unnamed-vector schema, `vector` is also reserved (it's the wire-level vector field).
- For a named-vectors schema, each declared vector field name is reserved instead.
